# Roadmap

## Phase 1 — MVP Foundation

- basic wallet connection
- source/destination chain selection
- cross-chain message sending demo
- event monitoring dashboard
- local Superchain simulation support

## Phase 2 — Productization

- user auth and team accounts
- subscription plans
- usage tracking
- analytics dashboard
- API scaffolding

## Phase 3 — Protocol Economics

- staking for relayers and liquidity providers
- governance token launch
- treasury reserves
- fee-sharing model

## Phase 4 — Enterprise Readiness

- SLA and monitoring
- secure operational controls
- custom routing rules
- multi-account support

## Phase 5 — Ecosystem Growth

- partnerships
- plugin integrations
- developer tooling
- documentation and tutorials

## Suggested launch milestone

The best initial milestone is not a token launch. It is a working product with clear recurring revenue from developer subscriptions and message usage.

A token should come after the platform has real user demand and operational value.
